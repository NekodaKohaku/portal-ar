# Asset provenance

This is an unofficial visual prototype. VRChat client assets retain their original owners' rights. Extraction does not grant permission to redistribute them. No VRChat branding or endorsement is claimed.

Unity shader effects have been approximated in GLSL. The game binaries are not modified or included. The extracted research inventory and Python tools are outside this website directory and are not part of the Pages deployment.

Three.js is MIT licensed; AR.js is MIT licensed. See the included vendor license files. Hiro marker files and calibration originate from the official AR.js 3.4.7 repository.

Noto Sans and Noto Sans CJK JP font data are extracted from the installed client's Font objects and losslessly repackaged as WOFF2. Font metadata includes Google copyright notices. These fonts are licensed under the SIL Open Font License 1.1; see vendor/NOTO-LICENSE.txt.
